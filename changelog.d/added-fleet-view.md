- **A Fleet pane shows who is working, and offers the verbs that govern them.** The extension was task-centric: `fleet_view`, `list_agents` and `task_query(view=stalled|doctor)` were never called by it at all, so answering "who is working right now?" meant reading raw JSON. The new **Fleet** view joins both planes on the shared agent id and renders one row per live agent — declared branch, head, dirty, how far behind base, observed activity, and a live countdown on every claim it holds — with this session marked as itself and board health beside it. Rows offer only the lifecycle verbs already legal for that row (renew, release, pause, resume, claim, recover), composed from the existing guards so the pane cannot offer what the server would refuse. Every value is self-reported (ADR-0035, ADR-0044): an undeclared field reads as unknown rather than being guessed, and a plane that is not answering is named instead of rendering a stale roster as current.
