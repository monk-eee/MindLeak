- **Added:** `lodestar-core` can now route `check_claim_overlap` through a federated repository's Ackplane claim registry instead of the local `tasks` table (ADR-0096 clause 5). `Lodestar::with_federated_claim_source` injects a `FederatedClaimSource` implementation; without one (the default), overlap detection is exactly today's local-table behavior. Ackplane's `ClaimDelegationService` gained the `ListActiveClaims` RPC (`ClaimStore::list_active`) so a federated repository's currently-active claims — owner, declared paths/symbols, and lease expiry — can actually be read from the registry. Wiring an `ackplane-client` implementation of `FederatedClaimSource` against this RPC is separate follow-on work — `lodestar-core` stays local and stdio-only (ADR-0004).
