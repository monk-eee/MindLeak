- **Design detail view cross-links Constitution/Work/Evidence references.** The Bridge `/design` page's detail view now shows `constitution_version_id`, `work_task_id`, and `evidence_id` (previously omitted entirely) as real links into the existing Constitution and Work pages, and materialization revisions' constitution version and work task references get the same treatment. The Evidence Board is scoped by `(repository, task)` rather than a bare evidence id, so an Evidence link is only constructed when the design also names its `work_task_id`; otherwise the id renders as plain text rather than a broken link.
