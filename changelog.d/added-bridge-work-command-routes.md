- **The Bridge can now issue Work commands.** `POST /api/v1/repositories/:repository_id/work/commands` (submit) and `.../commands/:command_id/confirm` (confirm) cover all ten ADR-0125 command kinds -- the five server-owned Work/Claim actions and the five ADR-0107 supervisor-directed directives -- against the existing `WorkCommandService`, never `WorkStore`/`ClaimStore` directly. Under the Bridge's loopback developer profile every command still correctly returns a typed `authorization_unavailable` outcome (ADR-0125 decision 2): this proves the full request/response contract, it does not grant the loopback profile new authority. A new `ackplane-workctl` CLI is a scriptable, non-browser caller of this same versioned API.
