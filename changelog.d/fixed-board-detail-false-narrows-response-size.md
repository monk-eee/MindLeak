- **`task_query(view="board")` takes an opt-in `detail=false` to skip its three per-row engine lookups.** `board()` (`crates/lodestar-mcp/src/tools/executive/tasks.rs`) enriched every task with a `scope`, `claim_window`, and `receipt` lookup unconditionally, which reached roughly 1.95 MB on this repository's own long-lived board. `detail=false` returns every task (nothing is dropped) but omits those three lookups plus the free-text `acceptance` field; the default stays `true` so no existing caller's contract changes. `scripts/board-health.mjs`, the VS Code extension's Design Board quick-pick, and its evidence refresh now pass `detail: false`, since none of them read the omitted fields.
