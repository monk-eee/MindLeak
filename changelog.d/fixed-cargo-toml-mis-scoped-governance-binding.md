- Fixed a recurring `drift` false-positive: the root `Cargo.toml` was governed by `goal:adr-0030-unique-per-process-agent-identity`, a goal about per-process session identity with nothing to do with `[workspace.dependencies]`. Every dependency change by any task not doing agent-identity work earned `drift` for that one file (observed live on ADR-0143 slice 1, PR #856, adding `deadpool-postgres`). Unbound via `constitution_define(action="unbind")`; `binding-audit.mjs` measures Rust source coverage only, so nothing it protects is affected. See `gaps.d/a-shared-manifest-governed-by-one-feature-goal-drifts-every-dependency-change.md`.
