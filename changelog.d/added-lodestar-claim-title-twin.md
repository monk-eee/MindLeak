- **Added:** `task_claim(step="claim")` now reports a live `title_twin` — a task under a different goal sharing the exact same title — whenever one exists, regardless of what scope (if any) either task declared. This closes the visibility gap where a scope-less claim was invisible to both `check_overlap` and `task_query(view="drafts")`, since both key on declared scope (ADR-0099). It never blocks the claim (ADR-0015): it only makes the collision visible instead of relying on the claimant to think to run `existing_work`.
