- **`compile_digest` renders a named, typed digest — a playbook/runbook/repository-guide — from current graph state through a deterministic template, never hand-authored prose (ADR-0101).** Ships `repository_guide` (agent roster, recent decisions, recently active files), composed entirely from existing tools (`counts`, `list_agents`, `snapshot`). Each compilation stores the result as a new `digest` node rather than editing a prior one — the same "assembled, not edited" discipline ADR-0056 already applies to the changelog, generalised to any typed document a consuming product wants to derive from the graph. `digest_status` reports whether a digest's recorded source snapshot still matches live graph state (`current`/`stale`, naming exactly which source node ids went missing) without ever regenerating the digest itself.
