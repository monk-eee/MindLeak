- **Fixed:** The Intent Plane's `knowledge_embeddings` table now declares `ON DELETE CASCADE` onto `knowledge`, so a vector can no longer outlive the lesson it describes. The table is created by the optional index pass rather than by `schema.sql`, and was written without the foreign key `knowledge_sources` already carries onto the same parent — so a decay prune in `store::knowledge`, or a lifecycle clear, would have left its vectors behind permanently with nothing to sweep them. This is the same defect the Memory Plane carried against its own `embeddings` table, where it reached 48,502 orphaned rows and 142.1 MiB before anyone looked; this ledger was measured at 813 lessons, 759 vectors and **zero orphans**, so it is fixed before it bled rather than after. Opening an affected ledger rebuilds the table with the constraint, discards anything that already leaked, and returns the freed pages to the filesystem.
