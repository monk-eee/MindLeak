- **`constitution_define` now advertises a valid array schema for structured import records, so strict MCP clients can load the Lodestar tool surface.** A bare `{"type": "array"}` with no `items` failed schema validation and made *every* Lodestar tool uncallable, not just this one. Its description is correspondingly tighter, because the default tool profile had no room left under the ADR-0059 token budget to add the `items` schema otherwise.
