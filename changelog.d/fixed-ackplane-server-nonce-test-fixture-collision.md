- **Fixed a Postgres-gated `enrollment_store`/`fleet` nonce collision found while validating an unrelated change.** `issue_challenge` was called from `enrollment_store::tests::activation_reuses_its_live_challenge_and_exact_replay_receipt` and `fleet::tests::an_enrolled_repository_without_a_projection_remains_visible_in_fleet` with fixed literal nonces (`[1; 32]`, `[2; 32]`, `[3; 32]`). `activation_challenges.nonce` carries a bare, tenant-independent unique constraint, so a second local run against the same persistent container (the normal way to validate a fix) collided on it. Added `test_support::unique_nonce()` (a wall-clock-nanosecond + atomic-counter combination, matching how real callers use `getrandom` in `enrollment_service.rs`) and switched both call sites to it.
