- **`ClaimSigner` is now backed by the OS credential facility.** `ackplane_client::auth::CredentialFacilitySigner` reads and writes a node's Ed25519 signing seed through the `keyring` crate (Windows Credential Manager, macOS Keychain, or Linux Secret Service), never a file, environment variable, or command-line argument (ADR-0085 decision 2, ADR-0100 decision 5). `lodestar_mcp::federation::resolve_identity` now resolves to it by default; the interim `SeedSigner`/`MINDLEAK_ACKPLANE_NODE_SIGNING_KEY_SEED` env-var path remains available as an explicit, documented non-hardened override for tests and constrained deployments.
