- **The server installer now collects the binaries a hand deploy sets aside, and can be asked to on its own.** Replacing a live server means renaming the running file rather than overwriting it — Windows permits the one and refuses the other — so every deploy leaves a copy behind. `pruneSupersededInstalls` matched only the `.old` name `installOne` writes, never the `.superseded` name a hand-run deploy uses, and it ran only as a side effect of a full install, which a deploy that copies a build in never performs. Measured on 2026-08-14: eight orphaned copies, 68.2 MiB, the oldest two weeks old. It now takes both names, still skipping anything a running server still holds, and `node scripts/install-servers.mjs --prune` reclaims them without reinstalling anything.
