- **A knowledge statement now starts as an unreviewed Candidate, and a real, authorized `activate` operation is the only path to Active (ADR-0113 decision 1).** `recall`/`active_page` only ever return Active rows, so an unreviewed candidate is invisible to both the gRPC recall path and the Bridge's read-only page until it is explicitly activated with a non-empty authorization basis. Every accepted activation appends one immutable receipt (`knowledge_activations`, ADR-0113 decision 7); `retire`/`reconfirm` are unaffected. Rows recorded before this change backfill as Active, so already-established guidance is unaffected.
