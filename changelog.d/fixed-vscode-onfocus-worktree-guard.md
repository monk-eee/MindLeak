- **The VS Code extension's focus tracking no longer boosts artifacts outside the tracked repository worktree.** `onFocus` skipped the same `repositoryWorktrees` membership check that `onSave`/`onDelete` already applied, so focusing a file in an unrelated multi-root folder that happened to share a repo-relative path (e.g. `src/index.ts`) silently boosted the tracked repository's identically-named artifact instead.
