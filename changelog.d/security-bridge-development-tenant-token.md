- **Security:** The Ackplane Bridge's loopback developer profile now derives its tenant identifier as `hex(SHA-256(salt || tenant_name))` instead of using `ACKPLANE_BRIDGE_DEVELOPMENT_TENANT` as a bare comparable string (ADR-0098 decision 3). The salt is a 32-byte per-installation secret generated once and persisted at the path named by the new required `ACKPLANE_BRIDGE_SALT_PATH` variable, so a tenant name guessed or found in a log cannot reconstruct the same token on another machine. This is a usability hardening of the single-operator loopback path, not authentication infrastructure — ADR-0094's refusal to bind non-loopback without a production verifier is unchanged.
