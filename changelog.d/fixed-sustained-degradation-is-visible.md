- **Fixed:** A degraded optional feature now says how long it has been failing, and says it unprompted. Autonomous indexing records one `skipped` per degraded run and then goes quiet on purpose — correct for a transient blip, and silent for an outage. Measured before this change: the autonomous index went **121 consecutive passes** unable to reach its embedding model, across four hours, with 21.4% of the graph unindexed, and every report of it was indistinguishable from the first. The only way it surfaced was reading the raw event table. The telemetry recommendation now states the duration (`autonomous_index has not succeeded in 4h12m and is degraded: …`) rather than a bare "is degraded", so an outage cannot read like a blip, and it reports every degraded tool instead of only the first. `open_session` additionally volunteers any optional work that has been failing for over half an hour, alongside the stale-build and replaced-binary notices already there — a fault an agent cannot see is a fault it assumes away.
