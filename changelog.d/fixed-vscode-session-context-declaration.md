- **The VS Code extension now declares and refreshes its Git working context on `open_session`.** An extension-originated session previously declared only `session_id`, leaving the fleet to guess at branch, commit, and dirty state (ADR-0044). It now reads branch, head commit, and dirty tree from VS Code's built-in Git extension through an injectable context provider, deriving base/behind only when a tracked upstream makes them reliably known, and re-declares them whenever the repository's state changes (attach, checkout, or a working-tree refresh).
