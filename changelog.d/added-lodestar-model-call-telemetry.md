- **Lodestar's own model calls now report token usage and cost, not just success or failure.** `decompose`/`judge`/`draft_question` could fail over to a deterministic fallback and say why, but a *successful* call left no record of what it cost — no way to answer "how many tokens has decomposition burned this week" without grepping a local server's own logs, if it kept any. `LlmClient` now captures the OpenAI-compatible `usage` field (prompt/completion/total tokens) from each `/chat/completions` response when the server reports one, exposed one-shot via `last_usage()` right after the call it describes. Each of the three call sites times its call and records it — operation, outcome, duration, tokens, model — to a new local table, best-effort like every other telemetry write here: a recording failure never changes the result of the call it observed. The new `model_telemetry` MCP tool reads it back: lifetime calls/errors and token totals, broken down per operation, answering even when no model is configured or reachable.
