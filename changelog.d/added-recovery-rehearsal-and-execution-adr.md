- ADR-0145 is accepted: Recovery gains a real design for the two capabilities ADR-0119 decision 6 named but never mechanically specified. Rehearsal restores an artifact into an isolated, ephemeral target (never `ACKPLANE_DATABASE_URL`) and runs real application-level integrity checks, distinct from the existing `inspect_snapshot_artifact`'s archive-format-only check. Production recovery execution reuses ADR-0134's dual-signing-key preview/confirmation pattern verbatim rather than inventing a new one, requires a fresh passing rehearsal of the exact same artifact digest, and confronts the blast-radius question `docs/ARCHITECTURE.md` already flags for Snapshot/Export: a platform-wide `pg_dump` artifact is not a valid tenant-scoped restore target, so production execution is refused outright unless the deployment is explicitly attested single-tenant. Design-only: no code ships with this ADR.
