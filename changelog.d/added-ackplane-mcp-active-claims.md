- `ackplane-mcp` gains `active_claims`, reading the claims Ackplane currently arbitrates for a repository by translating `ClaimDelegationService.ListActiveClaims` (ADR-0139 clause 1's read half). It is read-only and unsigned by design: unlike every mutating claim call, that RPC carries no `ClaimAuthentication` because it asks only what the arbiter already states about its own arbitration, so no signer is involved. `ackplane-client` gains the matching `list_active_claims` wrapper it was missing. Scope is taken from `MINDLEAK_ACKPLANE_TENANT_ID` and `MINDLEAK_ACKPLANE_REPOSITORY_ID`, and an unset or blank value is refused by name rather than sent as a blank scope, which would return an empty list indistinguishable from "this repository has no claims". Per ADR-0139 clause 3 the surface still exposes no `task_create` and no `task_transition` accepting a terminal state; calling either now earns a typed refusal naming ADR-0120 decision 8, distinct from the "unknown tool" refusal because the operation exists and only Ackplane's authority for it does not.
