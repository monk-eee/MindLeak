- ADR-0136 is accepted: Ackplane gains a thin MCP protocol adapter (`ackplane-mcp`) that translates MCP tool calls into its existing typed gRPC services, rather than forking `mindleak-core`/`lodestar-core` onto PostgreSQL. An MCP-speaking agent gets a path to the Industrial profile without a second, independently written implementation of decay, claim/lease, or conformance rules. The Local profile is unchanged: `mindleak-mcp`/`lodestar-mcp` keep their stdio-only, no-network-listener contract, and no runtime heuristic ever promotes a Local repository into the Industrial one. Accepting the decision does not make the switch usable end to end -- authentication for a non-enrolled MCP client (clause 4) and the domain-parity slices (clause 3) are sequenced follow-up work.
