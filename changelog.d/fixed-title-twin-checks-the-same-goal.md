- **`task_claim`'s `title_twin` field now checks the same goal, not a different one.** The shipped implementation (PR #508) reported a live title collision across *different* goals, which ADR-0099 explicitly says must stay unaffected — that case is legitimate (ADR-0015) and already reported separately by `task_create`'s `same_title_under_other_goals`. It now reports the same-goal collision the ADR (and the incident that motivated it) actually describes.
