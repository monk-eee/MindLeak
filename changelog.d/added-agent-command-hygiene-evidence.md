- **Added:** A new `tool_invocation` evidence kind captures the tool name and a bounded argument excerpt behind every agent-issued shell command, passively, at the same seam as existing execution capture — never self-reported (ADR-0127). A deterministic, zero-token classifier flags two shell-hygiene antipatterns (a native command like `git`/`cargo`/`npm` piped through a PowerShell-only cmdlet, or a direct `$LASTEXITCODE` read) and reports the finding through a new generic `observe_control` tool against the new `control:agent-command-hygiene`, bound at `observed` power to its own clause so a finding never exceeds `review` — retrospective only, never a runtime block.
