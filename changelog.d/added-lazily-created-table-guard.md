- **Added:** Both planes now guard the defect class that produced their orphaned-embedding leaks. A table built by a runtime `ensure_table` call never appears in `schema.sql`, so no review of the file where foreign keys live can see it — which is how `embeddings` and `knowledge_embeddings` each shipped without the cascade their siblings had, independently, in two separate crates. A test in each plane now pins the exact set of tables created outside its schema file and asserts every one of them declares a parent, so adding another fails until someone says so deliberately. Deliberately narrow: asserting that every table anywhere declares a foreign key would need a long allowlist of legitimate root tables and would decay into a rubber stamp.
