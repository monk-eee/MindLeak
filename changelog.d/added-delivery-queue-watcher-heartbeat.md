- **The delivery queue says when nothing is taking its turns.** Watch mode now writes a heartbeat every tick, and a one-shot run reads it: when armed pull requests are waiting and no watcher has beaten recently, the run says so and names `make queue-watch`. It stays silent when a watcher is running or when nothing is armed, and it distinguishes a watcher that stopped from one that was never started. Previously an unattended queue was indistinguishable from a queue with nothing to do, so armed work could sit behind `main` for hours with nothing reporting it.
