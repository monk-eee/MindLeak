- **The delivery queue says when nothing is taking its turns.** Watch mode now writes a heartbeat every tick, and a one-shot run reads it: when armed pull requests are waiting and no watcher has checked in recently, the run says so and names `make queue-watch`. It stays silent when a watcher is checking in or when nothing is armed, and it distinguishes a watcher that stopped from one that never checked in here. Previously an unattended queue was indistinguishable from a queue with nothing to do, so armed work could sit behind `main` for hours with nothing reporting it. Note for operators: a watcher already running when this lands predates the heartbeat and cannot check in until it is restarted, so the note will report it as absent — restart any long-lived `make queue-watch` once and it is visible from then on.
