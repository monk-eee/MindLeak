- **Fixed:** The semantic-recall `embeddings` table now declares `ON DELETE CASCADE` onto `nodes`, so a vector can no longer outlive the node it describes. The table is created by the optional index pass rather than by `schema.sql`, and was written without the foreign key every other child of `nodes` has — so every prune, re-ingest, and structural-snapshot replacement left its vectors behind permanently, with nothing to sweep them. Measured on a working graph before the fix: 48,502 orphaned rows holding 142.1 MiB, 74.3% of the table and roughly three times the live data beside it. Opening an affected database rebuilds the table with the constraint, discards what already leaked, and returns the freed pages to the filesystem. Measured end to end on a 421.5 MiB copy of that graph: 228.1 MiB afterwards, a 46% reduction, costing about 11 seconds on the single open that performs the migration (13.9s against 3.1s for an open with nothing to do) and nothing on every open after it.
