- **Fixed:** The semantic-recall `embeddings` table now declares `ON DELETE CASCADE` onto `nodes`, so a vector can no longer outlive the node it describes. The table is created by the optional index pass rather than by `schema.sql`, and was written without the foreign key every other child of `nodes` has — so every prune, re-ingest, and structural-snapshot replacement left its vectors behind permanently, with nothing to sweep them. Measured on a working graph before the fix: 48,502 orphaned rows holding 142.1 MiB, 74.3% of the table and roughly three times the live data beside it. Opening an affected database rebuilds the table with the constraint and discards what already leaked; the reclaimed pages are reused by SQLite rather than returned to the filesystem, so the file shrinks only after a `VACUUM`.
