- **`canonical-push` no longer silently blames "the Lodestar ledger is unreachable" for a bug in its own claim-gate batch.** The `fleet_view`/`open_session`/`board`/`overlap`/`board-by-branch` batch and the merge logic that follows it were wrapped in one bare `catch { reachable = false; }`, so a parse or shape defect anywhere in that block (`withReconciliationCandidates` choking on an unexpected result shape, for example) read identically to a genuinely down server or a stale binary, sending the reader toward a rebuild that would not help. The catch now logs the real thrown error before collapsing to `reachable = false`, so the two causes are distinguishable without instrumenting the script by hand.
