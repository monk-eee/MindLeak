- **`Synchronize` connections now authenticate with the node's enrolled signing key (ADR-0098 decision 1).** On stream open, `Hello` must name a `signing_key_id`; Ackplane issues a single-use, domain-separated nonce and the node proves possession by signing it before any event batch or heartbeat is accepted. A revoked, expired, retired, or unknown key refuses the connection outright, and an out-of-order or invalid handshake frame ends the stream rather than being silently ignored.
