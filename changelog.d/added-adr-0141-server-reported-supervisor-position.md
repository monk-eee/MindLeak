- ADR-0141 is proposed: Ackplane reports its own durable view of a supervisor's outbox frame position instead of echoing back the number the client just sent. `HelloAccepted.accepted_position` is currently sourced straight from `hello.last_accepted_position`, so ADR-0116 decision 7's reconciliation was comparing a value against its own reflection and its `IncompleteEvidence` arm could never fire — meaning a supervisor whose durable state was restored from an older copy or truncated is indistinguishable from one that has never run. The ADR proposes a distinctly named `supervisor_frame_position` rather than reusing `accepted_position`, because the two count different things: the ledger's event stream versus the supervisor outbox's own local frame sequence. It is optional so that "never seen this supervisor" stays distinguishable from "seen at zero", server-authored so it cannot become an echo by a longer route, and degrades to today's undetected behaviour rather than to a false verdict when either side is older. No wire or server change ships with the proposal.
