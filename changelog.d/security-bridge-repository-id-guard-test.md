- **Security:** The Ackplane Bridge now has a structural test guard (ADR-0098 decision 5) that fails if a new route handler or `FleetStore` query/mutation is added without an explicit tenant scope: every `FleetStore` method (other than the `connect` constructor) must take a `tenant_id: &str` parameter, and every Bridge route handler (other than the static `fleet_page`) must reference `state.tenant_id`. This is a lint/test-level guard, not a permissions engine — distinct per-role authorization remains deferred until ADR-0084 decision 4 (OIDC) delivers a real principal.
