- **Added:** A new `mindleak-coordinator` binary composes MindLeak and Lodestar into one agent-facing stdio MCP server (ADR-0097, first slice): `coordinator_open_session` opens both planes in one call with the same declared context and verifies they resolve the same `agent_id`/`repository_id`, naming whichever plane failed rather than presenting a partial open as complete; `coordinator_preflight` composes MindLeak's `check_overlap`, Lodestar's `task_query(view="overlap")`, and Lodestar's `advise` into one result with per-plane provenance -- the read a write should already have made. It spawns both existing servers as real children and opens neither plane's database directly. Decisions 4-8 of ADR-0097 (client-side Git observation, goal-less scope reservations, governance-bootstrap helpers, memory-source reconciliation, and the usage retrospective) remain future work.
