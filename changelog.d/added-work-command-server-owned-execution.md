- **Ackplane's Industrial Work command service can now confirm and execute a command's server-owned effect.** `CreateWork`/`RouteWork`/`AnswerWait`/`SubmitReview` mutate `work_tasks`/`work_task_history`/`work_task_waits`; `ReleaseLease` also mutates `delegated_claims`/`delegated_claim_history`, atomically with the command's own receipt. A task gains an optimistic-concurrency `version` and a `route_reference`. It still adds no HTTP route.
