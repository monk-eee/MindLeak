- **`compile_context` composes `recall`, `working_set`, and `evidence_for` into one bounded, ranked, token-budgeted context packet (ADR-0102).** Previously a caller wanting bounded, relevant context called these tools separately, then assembled, ranked, and trimmed the combination itself, with no shared bounding by an actual token cost. `compile_context` reuses each source's own already-decayed relevance score to rank candidates, includes them highest-first until `max_tokens` (bytes/4, the same convention the advertised tool surface already uses) is spent, and reports exactly what was excluded for budget reasons via `budget_report`. It invents no new data: `governing` passes through the caller's own Lodestar `advise()` result unfiltered, since this crate has no dependency on that plane — the same seam `promote_signals` already crosses by taking data as an argument rather than reaching back across planes internally.
