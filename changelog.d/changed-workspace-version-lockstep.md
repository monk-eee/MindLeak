- **The workspace and the VS Code extension are back on one version, now `0.1.7-alpha`.** The crates had been bumped to `0.1.6` in isolation while `editors/vscode/package.json` stayed at `0.1.5`, so a packaged extension shipped servers whose `server_version` disagreed with the extension carrying them — and because the extension packages its own binaries and prefers them over every other install, that skew decided which build actually ran. `0.1.6` is not reused: it was never released, but it was deployed widely enough to be reported as `server_version`, so recycling the number would make two different builds answer to one identity.
