### Added

- Added `NodeSyncConnection` (`ackplane-client::node_sync`), the first reusable client-side implementation of ADR-0116's authenticated `Synchronize` handshake: it opens the bidirectional stream, sends `Hello`, and completes the enrolled-key connection challenge through the existing `ClaimSigner` abstraction, returning a live connection only after `HelloAccepted` and `FlowControl` are observed. A wrong signature, an unknown signing key, or a revoked key surface as a typed `ClientError::ConnectionRefused` carrying the server's own `RejectionReason`, never a bare stream failure. The connection-challenge byte layout (`ConnectionChallengeBinding`, `connection_challenge_bytes`) moved to `ackplane_protocol::connection_challenge_auth`, shared by the server that verifies it and any client that now produces it; `ackplane_server::enrollment` re-exports it unchanged for existing callers.
