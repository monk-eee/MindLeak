- **Stale, contradicted, and overdue-for-revalidation knowledge is now visible in a bounded, read-only review queue (ADR-0113 decision 4).** Every active statement is classified at query time — never stored — as `current`, `approaching_expiry`, `contradicted`, or `overdue_for_revalidation`, from its effective weight, whether any evidence reference contradicts it, and whether an optional per-statement revalidation policy has elapsed. A contradiction always outranks an overdue policy rule, which always outranks ordinary decay. Bridge exposes this at `GET /api/v1/repositories/:repository_id/knowledge/revalidation-queue`, tenant/repository-scoped, with an allow-listed classification filter and a stable keyset cursor. This is read-only: no mutation route, policy-authoring surface, or automatic revalidation trigger is added.
