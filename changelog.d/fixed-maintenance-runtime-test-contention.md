- Serialized `mindleak-mcp`'s 3 file-backed-database maintenance runtime tests (`enabled_worker_runs_after_idle_and_joins_cleanly`, `active_request_blocks_idle_pass_until_completion`, `prune_runs_on_its_cadence_despite_continuous_request_activity`) against each other with a test-local mutex, fixing a `Busy("...migrating the schema was still locked...")` flake observed under parallel CI load (PR #524).
