- **Ackplane's event-batch path now surfaces a refusal as a typed error, and the two real consumers stopped hand-rolling the handshake.** `NodeSyncConnection::exchange_event_batch` publishes one batch and waits for its `BatchReceipt`, turning a `Rejection` into `ClientError::FrameRefused` carrying the server's own `RejectionReason` — the same treatment supervisor frames already had, and the handshake before them. `register-me` and the `enroll_and_sync` example now open a real `NodeSyncConnection` instead of repeating the Hello/ConnectionChallenge/ChallengeResponse/HelloAccepted/FlowControl exchange by hand. That fixes a real defect in `register-me`: a refused heartbeat landed in the same variable a receipt would have, so it printed `batch_receipt: ...` and then reported the node "enrolled and synchronizing" when the server had in fact refused the batch.
