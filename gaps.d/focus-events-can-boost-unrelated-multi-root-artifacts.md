- **VS Code focus events can boost an unrelated multi-root workspace file -- MEASURED 2026-08-26, OPEN.** `editors/vscode/src/extension.ts`'s `onSave` and `onDelete` verify `repositoryWorktrees.contains` before sending a path to the server, but `onFocus` computes `artifactId` and calls `boost_entity` without that guard. In a multi-root workspace, focusing an unrelated folder's `src/util.ts` can produce the same folder-relative `artifact:src/util.ts` id as the tracked repository's file and boost it in the shared graph. Impact: focus-derived relevance is silently attributed to the wrong artifact in exactly the worktree/multi-root layout the extension supports. Left for later: apply the worktree-membership guard to focus handling and add a handler-level regression for two roots with matching relative paths.
