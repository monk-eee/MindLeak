- **Replaying a withdrawn constitution proposal returns `proposed` while durable state stays withdrawn -- MEASURED 2026-08-26, OPEN.** `crates/ackplane-server/src/constitution_store/proposals.rs` treats byte-identical proposal replays as idempotent without reading or changing the stored status. After withdrawal, the Bridge handler in `crates/ackplane-bridge/src/handlers/repository/constitution.rs` still returns its hard-coded `status: "proposed"` response even though proposal listing reports the same row as `withdrawn`. Impact: clients receive a successful state claim that contradicts the durable record and have no way to reactivate the proposal under its existing identity.
