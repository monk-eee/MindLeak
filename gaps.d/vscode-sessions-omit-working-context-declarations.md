- **VS Code MCP sessions never declare their known Git working context -- MEASURED 2026-08-26, OPEN.** `editors/vscode/src/mcpClient.ts` calls `open_session` with only `session_id`, even though ADR-0035 requires clients to declare and refresh optional `branch`, `head_sha`, `base`, `dirty`, and `behind` context for fleet heuristics. The extension already has the active workspace and Git sensor, while its Fleet view renders those same fields; nevertheless every extension-originated session remains `unknown` for branch-aware overlap, staleness, divergence, and ownership clarity. Impact: the primary editor client silently degrades the coordination signals designed to distinguish same-branch collisions from cross-branch merge risk. Left for later: supply an injectable Git context to the MCP client at session registration and refresh it on repository state changes, with tests asserting the actual `open_session` payload.
