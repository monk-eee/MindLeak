- **`NodeSyncConnection::recv` still returns post-handshake `Rejection` frames raw for every non-supervisor path.** Slice 2 gave supervisor frames a typed round trip (`exchange_supervisor_frame` in [`crates/ackplane-client/src/node_sync.rs`](../crates/ackplane-client/src/node_sync.rs), converting a `Rejection` into `ClientError::FrameRefused`), but the event-batch path still calls `recv` directly and gets an ordinary frame back. Impact: a caller awaiting a `BatchReceipt` that is refused instead waits for a receipt that never arrives and reports a timeout, losing the server's own `RejectionReason` — exactly the failure mode slice 2 removed for supervisors, still live one frame type over. The typed machinery already exists, so closing it is a matter of routing the batch path through the same shape rather than new design. Left for later: slice 2's acceptance is scoped to supervisor registration, session, and heartbeat, and widening it here would have been an unrelated change riding along in a PR reviewed for something else.
