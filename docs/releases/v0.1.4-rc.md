The final release PR merged with every required check green. The tag workflow
then reran the repository quality gate and native release smoke on every target
architecture before publishing assets.

## Changelog and notes

The release was based on a drained merge queue. Every fragment on that exact
head was folded through
`node scripts/changelog.mjs --release 0.1.4`, leaving `Unreleased` empty and no
